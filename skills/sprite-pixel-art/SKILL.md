# 将角色概念图转成可在目标尺寸显示的像素样稿

先在原生画布画剪影，留出动作空间，再以亮、中、暗三组组织头发与衣服。优先保留刘海缺口、衣领转折等识别特征。只在材质转折处加像素簇。

提供原尺寸样稿、4 倍最近邻预览及色板。用同一帧比较手工修整、降采样和模型候选；记录工作流、种子及参考图。

## 来源与维护

RedCarpG/redcarpg-skills 实验版。沿用 ChroniQ 的样稿对照、实测取证与交接方法。修改规则时重跑 evals 中的案例并更新 manifest 版本。
