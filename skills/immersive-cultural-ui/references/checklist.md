# 交付前检查清单

逐条核对，能截图的截图作证据。做不到的条目（例如没有英文界面）写明「不适用」，不要默默跳过。

## 怎么检查

- **装了 `frontend-verification` skill 时，用它。** 它有现成的截图脚本，也记了无头 Chrome 的坑。这里只补这种风格特有的几点。
- **没装时：**
  - 优先用内置浏览器预览：真浏览器，能点、能读控制台、能切手机尺寸。
  - 要批量截图时用无头 Chrome：

    ```bash
    chrome --headless=new --hide-scrollbars --window-size=1440,900 --virtual-time-budget=6000 --screenshot=desk.png file:///…/index.html
    chrome --headless=new --force-prefers-reduced-motion --window-size=1440,900 --virtual-time-budget=6000 --screenshot=reduced.png file:///…/index.html
    ```

    Windows 上 Chrome 在 `C:\Program Files\Google\Chrome\Application\chrome.exe`。`--virtual-time-budget` 让页面先跑几秒，字体加载完，逐层亮起也走完。要截逐层亮起的中间状态，把它调小，例如 1500。
  - **手机宽度不要用无头的 `--window-size=375,…` 截。** 新版无头 Chrome 把布局宽度钳到至少 500，截出来的只是 500 宽布局被裁掉一块，看不出问题。在内置浏览器里切手机尺寸，或者用 frontend-verification 的 `shot.mjs`。
- **量横向滚动：** 在浏览器里运行 `document.documentElement.scrollWidth <= innerWidth`。
- **这种风格特有的验证坑：**
  - 无头和隐藏的预览面板里，`requestAnimationFrame` 可能不跑：视差、吸附停住不一定是 bug。逐层亮起用的是 `setTimeout`，不受影响。
  - 截图里的字像宋体，可能只是网页字体还没加载完。
  - 详见 `motion.md` 末尾。

## 清单

### 一幕与两种看法

- [ ] 1440×900 上，第一屏是一幕：主体完整可见，不用滚动，四角（或信息栏）的字都在屏内。
- [ ] 主体做大版（`.ts-hero`）：1280×720 上主体也整个放得下；1100–1280 宽度下装饰不挨着信息栏，挨着就不放。
- [ ] 第一屏不是一堆卡片，也没有表单挡在主体上方。
- [ ] 375 宽的手机上，内容依次排成一列，没有横向滚动。
- [ ] 有「详细」时，切换用交叉淡入淡出；「详细」里不播开场动画；两边信息不矛盾。

### 背景与对比

- [ ] 所有背景层上盖了一层暗纱。眯眼看截图，最亮的是主体，不是星空、雾或光晕。
- [ ] 正文和背景的对比度至少 4.5:1。骨白 `#ebe3cf` 在墨底上没问题；次要文字（55%）只用于短的辅助文字。
- [ ] 金色只用在线条和重点上，没有大面积金底。朱红全页只有一处。

### 装饰

- [ ] 每个装饰都有 `aria-hidden="true"`、`pointer-events: none`、`user-select: none`。
- [ ] 1100px 以下不显示，打印不显示，英文界面不显示中文书法批注。
- [ ] 在 1100、1280、1440px 三个宽度下，装饰不压任何字。
- [ ] 每句引文都说得出书名和篇名，并且和这一页的主题相关。没有编造的古文。
- [ ] 把装饰全部隐藏，信息一点不少。

### 动效

- [ ] keyframes 和 transition 只动 `opacity`、`transform`、`translate`、`scale`、`rotate`。描线的 `stroke-dashoffset` 和流光的 `background-position` 这类小面积、一次性的例外，要心里有数。
- [ ] 景深：至少两层以不同速度、不同方向错开；会动的背景层放大了 3–4%，移动时不露边。
- [ ] 鼠标不动时，没有逐帧脚本在跑（Performance 面板里没有持续的 rAF）。
- [ ] 逐层亮起可以「跳过」，放完可以「重看」。说明行有 `aria-live="polite"`。
- [ ] 仪式感的动画每天只播一次，日期按本地日期记。
- [ ] 打开 `prefers-reduced-motion`：没有视差，没有流星，没有漂移和呼吸，逐层亮起直接全部显示，切换不过渡。
- [ ] 分段吸附（如果有）：读到长区块中间不会被拽走；滑动途中一碰滚轮就停。

### 文字与字体

- [ ] 竖排里没有阿拉伯数字。
- [ ] 竖排的长列表逐项看过，最长的数据下也不重叠，不压到下面的内容。
- [ ] 站酷小薇没有设 bold；要细读的小字（表格、密集列表、长说明）没有用它。
- [ ] 西文数字加了 `lining-nums`。
- [ ] 内联进 HTML 的脚本里（包括注释）没有出现结束 script 标签的原文，否则脚本会在那里被截断而且不报错。打开页面后在控制台确认没有报错，`window.Immersive` 之类的对象确实存在。
- [ ] 中文字体按需加载：@fontsource 切片，或 Google Fonts（书法装饰用 `text=`）。字体切片没进 PWA 预缓存。
- [ ] 大号显示的字过了一遍，没有易误读的字形，例如站酷小薇的「农」。

### 语言

- [ ] 繁體（如果有）：书法批注整段换成楷体；领域专有名词的用字核对过。
- [ ] 英文界面（如果有）：
  - 竖排改成横排，字距收到 `.06em`；
  - 文字不溢出，四角的字不压到主体；
  - 单复数正确；
  - 没有中英文直接拼接（「丙午Year」）；
  - 术语不是生硬的直译。
- [ ] 标题照人们平常的说法，不为了氛围写拗口的话。

### 交互

- [ ] 导航、网格、场景画面拖动时不选中文字；内容区和输入框可以选。
- [ ] 弹出面板不透明，后面的字不透上来。淡化是加在按钮自己身上，不是加在父元素上。
- [ ] 滑动的指示（◆、光框）在窗口尺寸变化后、从别的页切回来后，位置仍然对。
- [ ] 键盘能走到所有按钮，焦点看得见（金线描出）。

### 打印与性能

- [ ] 打印预览里没有星空、雾、光点、装饰和说明行，正文可读。
- [ ] 页面自己的样式里没有写死浅色（例如正文写成 `rgb(235 227 207 / .82)`），都用 `var(--text)`、`var(--muted)` 这些变量。写死的浅色在打印时不会跟着变深，印出来几乎看不见。
- [ ] 星空、纸纹、雾只画一次，之后只移动，不重画。
- [ ] 标签页隐藏时不放流星。
