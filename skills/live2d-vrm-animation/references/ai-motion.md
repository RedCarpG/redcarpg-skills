# 让 AI 生成或修改表情、动作

原项目做了两个工作台（Live2D、VRM），用户用一句话描述，Claude 生成表情或动作，再用滑杆、关键帧微调。下面是试过可行的数据格式和校验规则。

## 共同的做法

- **只给 AI 文字数据，不给图。** 参数名、范围、默认值、显示名、现有表情或动作的值，足够它推理。
- **写目标值，不写差值。** 差值容易累加出错，目标值好校验。
- **回来的结果严格校验，出错就把错误发回去，最多重试一次。** AI 说做不到（回 `unsupported`，比如「转个身」）就不重试，直接告诉用户。
- **首帧、末帧自动补成默认姿势。** 播完不会留下歪着的头、举着的手。
- **大片段只交一部分：** 已有动作交给 AI 改时，只发动得最多的 24 条曲线，其余原样并回去；每条曲线先简化到 30 帧以内（贝塞尔段取中点；烘焙出来几百个点的要减）。
- **实测：** AI 38 秒回来一个 3.2 秒、4 根骨头 5 条曲线的 VRM 挥手，举手和摆前臂都对。

## Live2D

**给 AI 哪些参数：** 自动探测哪些参数「有用」。

- 把参数推到最大、最小，看顶点、透明度、颜色有没有变。
- 不要再分「动的是头还是身体」：长头发会让判断出错。
- 模型自带表情、动作用到的参数，探测说没变化也要算上。漏过一个脸红参数，AI 就说「模型没有脸红」。
- 实测：509 个参数的模型给 AI 78 个；第一次探测约 20 秒，画面最长卡 0.4 秒。

**每个参数给：** 名字、范围、默认值、cdi3 显示名、现有表情里的值。cdi3 显示名可能是噪音，同一个显示名出现在 ≥ 3 个参数上就不用。

**校验规则：**

| 项 | 规则 |
|---|---|
| 参数 | 必须存在 |
| 物理输出 | 不能写；报错时告诉它该写哪个输入（`physics3.json` 里权重最大的输入） |
| 值 | 超范围就截断 |
| 时长 | 0.2–20 秒 |
| 关键帧间隔 | ≥ 0.05 秒 |
| 每条曲线 | ≤ 60 帧 |
| 曲线条数 | ≤ 24 条 |

**存成文件：** 表情存 exp3（默认值 0 的参数 `Add`，值 = 目标 − 默认；默认值不为 0 的 `Multiply`，值 = 目标 ÷ 默认）；动作存 motion3。不是参数的曲线（部件显隐）改过以后就不保留。

## VRM

**给 AI：** 能用的骨头（VRM 标准名）和**每个轴的正负号**，比如 `rightUpperArm.z` 是「负 = 抬高」、`head.x` 是「正 = 低头」，左右镜像时 y 和 z 反号。不写清楚，AI 一半的动作方向是反的。

**起点和终点：** 站姿（手放下、手指微弯），不用 T 字。

**写文件：** 按 30 fps 采样成四元数，存 VRMA。单测把 VRMA 写出来，再用 three-vrm 读回去，每帧对得上。

**表情、手型、手碰身上，写在 JSON 里，不写进片段：** 片段里的表情会被每帧的状态表情、眨眼、口型盖掉。AI 回的动作 JSON 可以多三项（`references/vrm.md` 第 23–25 条）：

```json
{ "duration": 3.4, "curves": { "…": [[0, 0], [1, 10]] },
  "face":  { "mood": "sleepy", "beats": [[0.5, "aa", 0], [1.0, "aa", 0.9], [2.0, "aa", 0.9], [2.5, "aa", 0]] },
  "hands": { "right": [[0.4, "flat"], [2.5, "relaxed"]] },
  "reach": [{ "hand": "right", "to": "mouth", "from": 0.8, "until": 2.2 }] }
```

| 项 | 规则 |
|---|---|
| `face.mood` | 只能是列给它的状态名 |
| `face.beats` | 表情只能是 VRM 预设名；权重截到 0–1；时间在 0 到 duration，同一个表情两点至少隔 0.05 秒；最多 12 个；`blink` ≥ 0.8 一段最长 2 秒；每个表情最后不是 0 的补一个 0 |
| `hands` | 只能 left、right；手型只能是列给它的那几个；每只手 1–12 个点 |
| `reach` | 最多 4 个；hand 是 left、right；to 只能是列给它的目标；from < until，都在动作长度内 |

说明里写清楚每个手型、目标的意思，以及「挥手、伸懒腰手张开；捂嘴并拢；托腮弯着；放下手前换回放松」「要碰到身上的写 reach，角度只要大概对」。存的时候把这三项放进 VRMA 的 `asset.extras`，读回来再检查一遍（文件可能是别处来的）。

## 检查

- 生成后自动播一遍，逐帧记几根主要骨头（参数）的值，确认首尾回到默认、中间没有超范围。
- 至少在两个不同的模型上看一遍（比例不同的模型，手会穿进身体或够不到脸）。
- 让用户能一键撤回到生成前。
