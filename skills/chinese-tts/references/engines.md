# 引擎和工程

数字都是 2026-10 至 11 在一台 Windows 电脑上量的：8 GB 显存，CPU 没有 VNNI 指令。换了硬件要重新量，但「哪种做法更快」的结论一般站得住。

## 1. 切句和节奏

- 第一段只切到第一个逗号，越早出声越好；之后超过 40 字在逗号处切。
- `…？！` 后面紧跟的同类标点跟着这一句走，不单独成句。
- 合成只比念到的地方提前约 20 秒。再多的话显卡一直忙，打断时合成好的也白费。
- 显示和声音配合（有字幕、气泡时）：外来事件的声音不要比字先到，等字出现时再发「念这句」；字只打到正在念的那一句；声音迟迟不来要有保底（还没出过声 6 秒，念过几句后 20 秒，60 秒没声音就当念完），不然界面卡在「正在说」。

## 2. CPU 引擎

- **没有 VNNI 的 CPU 上，int8 反而更慢。** Kokoro int8 实时率 1.7–4.3（比实时还慢），fp32 是 0.57–0.71；4 线程比 6 线程快。
- **Matcha**：2 线程一句 180–420 ms（实时率 0.05–0.10）；第一个字到达后 0.65 秒出第一段音频。第一次碰到英文时 espeak 初始化约 1 秒。适合当后备和「主引擎还没好时先顶上」。
- **英文会被静默跳过：** Kokoro 不念 `GitHub`、`PR`、`%` 这类词典外的词。`sherpa-onnx-node` 2.0.0 去掉了 espeak，英文全被跳过，原项目锁在 1.13.8。升级前专门验证英文。

## 3. GPU 引擎

- CosyVoice3 在 Windows 原生 PyTorch 上实时率约 1.5（比实时慢）。Qwen3-TTS 实时率 9–12，而且不支持流式。
- **换成 WSL2 + vLLM 后：** 首段 0.75–1.06 秒，实时率 0.34–0.64，显存峰值 4.8 GB；从启动到就绪约 2 分钟。
- WSL 里要把 Windows 的 PATH 去掉，否则 vLLM 编译时会找到 Windows 的 `nvcc` 而出错。
- 服务只绑 127.0.0.1；WSL2 默认的 localhost 转发就够，不用改 `.wslconfig`。
- **带情绪：** CosyVoice 用缓存的说话人时会忽略传进去的指令，所以每种情绪在启动时带着指令各缓存一份。这样带情绪的句子首段 0.86–1.48 秒，和不带情绪一样。流式合成不能调语速（会报错）。
- **显存：** 8 GB 放不下两个大模型（生成声音的模型 4–5 GB + 常驻 CosyVoice 4.8 GB）。要用另一个模型时，先停常驻的，由 CPU 的 Matcha 顶上。
- 闲着很久时可以把 GPU 服务停掉（原项目：闲置后 WSL 内存降到 913 MB），再开口先由 CPU 引擎顶上，GPU 服务在后台重新拉起。

## 4. 取消

- 连接一断就调 vLLM 的 `abort_request`，并往 token 队列塞一个结束符。没这么做之前，取消后下一句要等 4.9 秒；做了以后 0.8–1.7 秒。
- 长回复的字早就收完了，按「这次聊天」的 id 去取消会找不到它，所以打断要单独发一条「别念了」，清掉排队和正在念的。

## 5. 缓存

- 实测：没合成过的句子 CosyVoice 首块 2.6–3 秒（原来估的是 0.2–0.4 秒）；短句「嗯。」0.8 秒；命中网关缓存 6 毫秒。
- 用户一开始说话（按下语音键、或者检测到开口），就在后台把垫话合成一遍（10 分钟内不重复）。说完以后几毫秒就出声。
- 回复第一句如果也只是「嗯」「好的」，就不念，免得说两遍。
- 换了声音、改了垫话以后，第一次还是慢的。

## 6. 后备音源和就绪

- 主音源没就绪，或者一开口就出错，换后备念。念到一半才出错就不重念，免得重复。
- **HTTP 起来了不等于模型好了：** 原项目的网关 HTTP 起来后，引擎还要约 3 秒才加载好，这期间来的三句都被 503 拒掉，没有声音。改成遇到 503 每 1 秒重试，最多等 30 秒。
- 声音服务没就绪时，别的启动步骤不要等它。

## 7. 生成新声音

- 用文字描述生成声音，不克隆真人；用户要模仿真人或已有角色时拒绝。
- 生成后用 Whisper small 把音频转回文字，和原文比，相似度 ≥ 0.85 才留，最多重试 3 次。给 Whisper 传 `initial_prompt` 反而识别成乱码。

## 8. 语音输入和插话

- 只有底噪时 SenseVoice 会冒出一个猜的小词，所以像在说话的部分不到 0.25 秒就不交给识别。SenseVoice 首次加载约 2.6 秒，按下按钮就先加载。
- 电脑在放的音乐、视频会被当成用户说话：对话中截取系统声音，有声音就先不听。但要把自己念的话排除掉，否则自己一开口就被当成「电脑在放声音」，插话就关了。
- 用音箱时让用户插话：先学回声比例；麦克风比该有的回声响 2.5 倍、持续约 0.34 秒，就先把自己压低约 -12 dB；之后 0.45 秒里还响就停下。模拟 36 种组合，自己念的时候没有误停过；用户开口后 0.47–0.64 秒停下。

## 9. 安装

- WebView2 默认要先点过页面才能出声：加启动参数 `--autoplay-policy=no-user-gesture-required`。
- 按需安装大模型：所有步骤能断点续装；uv 固定版本并核对 sha256；不碰系统里原来的 Python。
- 约 30 GB 的模型不放 `AppData\Roaming`（会跟着账号漫游），默认装到剩余空间最多的非系统盘。
- 用 WSL 的，卸载前先 `wsl --unregister`，否则留下一个坏掉的发行版。
