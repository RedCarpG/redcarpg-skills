# tianshu — 天书（夜色、金线、薄雾、宣纸）

- **School**：Specialty / Genre，东方古典与神秘学。不在 web-design-engineer 的 25 个配方里，是 immersive-cultural-ui 自带的锚点。
- **Vibe**：夜色里的一幕。深墨或深靛的底，细金线勾出主体，压暗的星空和薄雾退在后面，骨白的字，少量竖排，最淡的一层是书法批注。
- **Best for**：命理排盘、黄历与节气、星图与占星、塔罗、典籍与诗词、博物馆的器物与展览、节庆和有仪式感的产品页。
- **Touchstone**（用之前先搜图核对，不要凭记忆）：
  - 古星图：苏州石刻天文图（南宋淳祐年间），敦煌星图（唐）。看它们的细线、同心圆、刻度和绕圈排的文字。
  - 罗盘（罗经）：一圈套一圈的刻度和字，中心是天池。
  - 黄历和线装书：竖排，从右往左，栏线，朱印。
  - 实作：ChroniQ（星曆）「天书」界面的八字、紫微、今日三页。

**Palette**

两套底色，共用金色、骨白和朱红。

- **东方暖夜**（八字、紫微、黄历、典籍、博物馆）：
  - 底：墨 `#0a0807`。整页从上往下渐变：`#120d0a` → `#0a0807`（60%）→ `#070605`。
  - 面板：`#17120e`、`#211a14`。只给抽屉和弹出面板用，卡片是透明的。
  - 主体下的暗盘：`rgb(10 8 6 / .42)`，模糊 5px，让边缘融进雾里。
- **西方星空**（占星、塔罗、西方星座）：
  - 底：深靛 `#06061a`。渐变：`#0a0a26` → `#06061a`（55%）→ `#04040f`。
  - 面板：`#0e0f2a`、`#161838`。
- **共用：**
  - 字：骨白 `#ebe3cf`。次要文字是骨白 55%，细线是骨白 12%。
  - 强调：金 `#dcbc7c`。淡金底 12%，金边 40%，光晕 55%。金只用在线条和重点上，不铺大面积底色。
  - 第二强调：朱红 `#e0503a`。全页只给最要紧的那一处，例如命宫、印章、「本命」。
  - 批注的墨：褐 `#b98a5a`。标题下枯笔的墨：`#c69a62`。
  - 吉凶：宜 `#8fc79a`，忌 `#ff8a73`。西方相位：柔相位蓝 `#9fb4ff`，硬相位红 `#ff8a73`。
  - 五行（数据本身是五行时才用）：木 `#79c08e`、火 `#ef6b55`、土 `#d9a95e`、金 `#efe6cf`、水 `#7ea6f0`。
- **氛围层**（全部压在暗纱下）：
  - 光雾：几团大径向渐变，椭圆，70% 处渐隐到透明。
    - 东方：顶部正中一团朱红 .18，左上一团琥珀 `rgb(130 88 52 / .32)`，右下一团褐 `rgb(96 62 40 / .26)`。
    - 西方：顶部正中一团靛 `rgb(111 143 240 / .2)`，右上一团紫 `rgb(140 90 220 / .24)`，左侧一团紫 `rgb(90 60 180 / .16)`。
    - 都再加一圈四周压黑的暗角：45% 处起，到边缘黑 .5–.55。
  - 雾：分形噪声，`baseFrequency 0.0032 0.0055`，4 个八度；只留噪声浓的地方。东方暖灰，西方冷紫灰。不透明度 .24。
  - 光点：东方 110 个，西方 150 个。半径 0.4–2.4，不透明度 .15–.75，各自 9s 明灭。
  - 宣纸纤维（只用于东方）：分形噪声 `0.035 0.11`，横向长纤维，`mix-blend-mode: screen`，不透明度 .07。
  - 颗粒：分形噪声 0.9，去色，`overlay`，不透明度 .28。
  - 背后的星空：.62。
  - 暗纱：东方 `rgb(5 4 3 / .3)`，西方 `rgb(3 3 12 / .28)`，盖住上面所有层。
- **换主色**（主题需要时）：
  - 只换底色的色相和光雾的颜色。金、骨白、暗纱、各层不透明度都不动。
  - 例：青绿山水可以用深青底 `#06100e` 配青绿光雾；朱砂仪式感可以把光雾的朱红加到 .24。
  - 这些变体没有在真实项目里验证过。先当一个概念给用户看，确认后再用。

**Typography**

- **一幕里的字：** 站酷小薇 ZCOOL XiaoWei 400。笔画纤细、收笔利落，近于瘦金。
  - 只有这一个字重：不要设 bold，浏览器的假粗体很难看。
  - 一幕里的短标签（11–13px）可以用它；要细读的小字（「详细」里的表格、密集的星曜）它太细，改用思源宋体。
- **标题和导航：** 思源宋体 Noto Serif SC。标题 600，辅助文字 400。
- **西文和数字：** Cormorant Garamond 500–600，`font-variant-numeric: lining-nums`。
  - 字体栈里把它排在中文字体前面：西文和数字落到 Cormorant，中文自动落到后面的站酷小薇或思源宋体。
- **书法装饰：** 马善政 Ma Shan Zheng 400，只做装饰。繁體下换系统楷体。
- **正文：** 系统无衬线。
- **字号：**
  - 大号日期：`clamp(120px, 16vw, 200px)`，行高 .92；手机 96px。
  - 主体中心的大字：78px。
  - 四角立着的要素：40px，手机 32px。
  - 竖排题字 30px，竖排正文 16px，竖排小字 13px。
  - 拉丁小标（kicker）：12px，大写，字距 .5em。
  - 小标签：11px，字距 .3em。
- **字距：**
  - 中文标题 .24em。
  - 竖排 .3em，行高 1.5。
  - 安静按钮 .06–.12em。
  - 英文界面一律收到 .06em。

**Spacing**

- 阶梯：4 / 8 / 12 / 18 / 26 / 40。
- 一幕在 900px 以上最少 700px 高，内容垂直居中。四角离边 3%。
- 主体宽 `min(600px, 100%)`。屏幕窄时给四角让地方：`min(600px, 100% - 440px)`。
- 主体做大版（未验证）：主体一栏和信息一栏 1.9 : 1，中间 `clamp(24px, 4vw, 64px)`；主体宽 `min(100%, (100svh - 120px) × 宽高比)`；信息栏最窄 260px。

**Radius / Shadow / Motion character**

- **圆角：** 没有。卡片的框、底色、圆角、阴影全部去掉。只有印章有 2–3px 的小圆角。
- **阴影：** 不用投影，用光：
  - 发光的线：`drop-shadow(0 0 3px rgb(220 188 124 / .7))`；
  - 点亮的大字：`text-shadow: 0 0 16px currentColor`；
  - 弹出面板：才用一道真正的暗影 `0 12px 32px rgb(0 0 0 / .4)`。
- **动效性格：** 慢，像墨在纸上洇开。
  - 进场 0.45–1.1s，缓出 `cubic-bezier(.2, .7, .2, 1)`。
  - 环境循环很长：呼吸 5s，光点 9s，雾漂移 80s，刻度旋转 240s。
  - 详见 `motion.md`。

**Signature moves**

- **发光的细金线画主体：**
  - 线宽 0.5–1.1px，金色，不透明度 .3–.85。最外一圈最亮，加光晕。
  - 底下垫一块模糊的半透明暗盘，盘的边缘融进雾里，透出后面的星空。
- **点亮而不是填色：**
  - 用到的部分发光，其余沉在 .2–.4。
  - 选中的东西套一圈金色光框，不填实底。
  - 主体缓缓明灭（.78 ↔ 1，5s）。
- **四角放字，像老星图的版式：**
  - 右上：主语，大号金字题头加两三行竖排。
  - 左上：来历和背景。
  - 左下：要素像碑一样立着（字 40px，上面小标签）。
  - 右下：关系与结论。
  - 西方主题按西方的习惯横着读：左上是标题（拉丁小标 NATAL CHART 之类，下面两行中文），右上放统计，四角都横排，不竖排。
- **另一种：主体做大（还没在真实项目里用过）：**
  - 给器物、画作、塑像、单张牌这类「主体本身就有分量」的页面。
  - 主体偏一侧，占一大半宽度；信息收进另一侧一栏：竖排题头（64px 左右）加两三列，下面一个大数字（Cormorant 52px）和一两行说明。
  - 上方落一束淡金的光（中心 .18），脚下一圈落地的光（.1），都用 screen 混合压在主体上面，只提亮。
  - 和四角版各出一个概念给用户挑。
- **没有卡片：** 区块之间只有一道两端渐隐的骨白细线（12%）。标题是金色宽字距，下面一笔褐色枯笔。
- **安静控件：** 按钮是字，悬停时描出金线；选中的是金字加淡金底；主按钮夹在两道金线之间。
- **一点朱红，一层淡墨：**
  - 全页只有一处朱红光。
  - 最淡的一层是褐色书法批注，只在宽屏的留白里。

**Avoid**

- **背景太亮。** 每层单看都淡，叠起来就抢。先加暗纱，再问用户。
- **金色太多。** 金是线和重点；金底大色块、金色渐变按钮会变成「春节促销」。
- **红金堆满全页。** 朱红只给一处。
- **现代 SaaS 的痕迹：** 胶囊按钮、圆角卡片、卡片阴影、渐变实底按钮、emoji 图标。
- **站酷小薇加粗，书法字体做正文或小字。**
- **装饰：**
  - 编造的古文、无出处的「古语」；
  - 随机汉字、符文、八卦图当底纹；
  - 装饰压在内容上。
- **竖排里的阿拉伯数字。**

**AI prompt seed**

需要配图时（例如主体背后的星图、器物照片的底），这样要：

> Ancient Chinese star chart engraved in thin glowing gold lines on a near-black warm ink background, faint warm mist drifting, very subtle rice-paper fibre texture, concentric rings and fine tick marks, no text, no people, calm, minimal, 16:9.

西方版把 warm ink 换成 deep indigo night，mist 换成 faint violet nebula。

**Don't use when**

- 用户要明亮、轻快、亲和或商务的感觉。
- 天天用、以表格和表单为主的工具。只借安静控件和「详细」的写法。
- 品牌已有视觉规范。
- 内容和东方、古典、神秘学无关。
