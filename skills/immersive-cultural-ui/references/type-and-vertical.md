# 竖排与字体

## 字体分工

| 用在哪 | 字体 | 字重 | 说明 |
|---|---|---|---|
| 一幕里的字：主体上的字、四角竖排、立着的要素 | 站酷小薇 ZCOOL XiaoWei | 400，只有这一个 | 笔画纤细、收笔利落，近于瘦金。不要设 bold。一幕里的短标签可以用；要细读的小字（表格、密集列表）太细，改用思源宋体 |
| 标题、导航、日历详情 | 思源宋体 Noto Serif SC | 600 标题，400 辅助 | 页面的主要衬线体 |
| 西文、数字、拉丁小标 | Cormorant Garamond | 500–600 | 必加 `font-variant-numeric: lining-nums` |
| 书法装饰 | 马善政 Ma Shan Zheng | 400 | 只做装饰。只有简体字形 |
| 正文 | 系统无衬线 | 400 | 长段说明用它，读着不累 |

以上都是 SIL 开放字体许可，可以随网站分发。

**字体栈的顺序：** 西文字体排在最前面。浏览器按字找字体：拉丁字母和数字在 Cormorant 里有，就用它；汉字它没有，自动落到后面的中文字体。一个栈就管住了中西两套：

```css
--font-scene: 'Cormorant Garamond', 'ZCOOL XiaoWei', 'Noto Serif SC', 'Songti SC', serif;
--font-title: 'Cormorant Garamond', 'Noto Serif SC', 'Songti SC', 'STSong', serif;
```

## 按需加载

中文字体一个字重就有几 MB，不能整包下载。

- **项目里（Vite、webpack 等）：** 用 `@fontsource/<名字>/<字重>.css`。它把中文字体切成上百片，每片带 `unicode-range`，页面上出现哪些字，浏览器才下载那几片。
  - 只 import 用到的字重。
  - 站酷小薇、马善政只在用到的那页 import，不放进入口文件。
  - 首屏要用的标题字体可以在应用启动后再 `import()`。之前先用系统宋体，不挡首屏。
- **单个 HTML 文件：** 用 Google Fonts。它的中文字体也按 `unicode-range` 切片。
  - 只用到几个字的书法装饰，加 `text=` 参数只取这几个字，例如 `https://fonts.googleapis.com/css2?family=Ma+Shan+Zheng&text=水始冰&display=swap`。
  - 字要 URL 编码；装饰的字改了，记得同步改这里。
- **PWA：** 字体切片不要进预缓存清单，否则安装时会下载全部几百片。让它们在第一次用到时进运行时缓存。离线时还没取过的那片会回退到系统字体，可以接受。
- **启动画面：** 要在第一帧就显示品牌字，可以单独裁一份只含那几个字的小字体（几 KB）随页面预载。

## 繁體

- **马善政只有简体字形。** 繁體界面下，批注里一半是书法、一半回退成系统字体，非常难看。繁體下整段改用系统楷体：

  ```css
  :root[lang='zh-Hant'] { --font-brush: 'Kaiti TC', 'BiauKai', 'DFKai-SB', 'STKaiti', 'KaiTi', serif; }
  ```

- **用字：** 简繁转换用 OpenCC 这类按词组转换的库，然后单独指定领域用字。命理里常见的几个：
  - 地支「丑」不作「醜」；
  - 刑冲的「冲」作「沖」，不作「衝」；
  - 「天干」不作「天幹」，「斗」宿不作「鬥」。

  别的领域也会有自己的例外，上线前请懂行的人看一遍。

## 易误读的字形

装饰字体和细字体里，有些字会被认错。上线前把页面上出现的字过一遍，尤其是大号显示的字。

- 站酷小薇的「农」像「衣」：农历的「农」大字显示时要换字体。
- Cormorant 的旧式数字「1」像大写「I」：加 `font-variant-numeric: lining-nums`。
- 书法字体的草写可能和别的字相近。批注只用笔画清楚的行楷，不用狂草。

## 竖排

### 基本写法

```css
.ts-vertical {
  writing-mode: vertical-rl;   /* 字从上往下，列从右往左 */
  display: flex;
  flex-direction: column;      /* 竖排里，column 的方向是从右往左：每个子元素一列 */
  gap: 12px;
  letter-spacing: .3em;
  line-height: 1.5;
}
```

- 每一列一个元素。题头列用大号金字（30px），其余 16px，最后一列小字 13px、淡色。
- 竖排里，项与项之间用全角空格「　」隔开；英文界面换成「 · 」。

### 数字写成汉字

阿拉伯数字竖排时会横躺。写成汉字：

- 一般数：`hanNumber(23)` → 二十三（99 以内）。
- 年份逐位写：`hanDigits(2026)` → 二〇二六。
- 时刻：`hanTime('15:02')` → 十五时〇二分；整点写「整」。

三个函数都在 `code/immersive.js`。

另一种做法是 `text-combine-upright: all`（两位数横着挤进一个字的位置）。来源项目没用它，用之前先在目标浏览器里试。

### 长列表

- 竖排的长列表（宜忌、要素、引文）加 `word-break: keep-all`，只在项与项之间换列，不把一个词拆到两列。
- 再给它设 `max-height`（例如 `13em`），让它到高度就折到下一列，不会一直往下长、压到下面的内容。
- 六项刚好排两列。项更多时，只显示前几项，其余放进「详细」。
- 长列表竖排时容易互相重叠。每一项都要看一遍：
  - 最长的那一天的数据；
  - 1100–1440px 之间的几个宽度。

### 什么时候改横排

- **英文界面：** 一律横排，字距收到 `.06em`，居中。
- **手机上（900px 以下）：**
  - 短的题头列（两三列）可以保留竖排。它是这一幕的标志。
  - 长列表、多列的边注改横排，居中，字距 `.1em`。
  - 四角的东西依次排成一列：主语 → 主体 → 要素 → 关系 → 来历。

### 标点

- 竖排里用全角标点，项与项之间用全角空格「　」。
- 引号、书名号要转成竖排的形式（「」显示成﹁﹂）。这要字体带竖排字形（OpenType 的 `vert`）。思源宋体有；装饰字体不一定有，用之前截图看一眼。
