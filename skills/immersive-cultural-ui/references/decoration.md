# 装饰

装饰是这一风格的「最后一层淡墨」：书法批注、星斗线描、标题下的枯笔、主体背后的大字、宣纸纤维。它只做视觉辅助。

## 规则

1. **很淡。** 越大越淡：
   - 主体背后铺的大字：.06，`mix-blend-mode: screen`；
   - 宣纸纤维：.07；
   - 拉丁铭文：.45；
   - 标题下的枯笔：.55；
   - 星斗线描：整体 .6，线本身再乘 .45；
   - 书法批注：.62，褐色 `#b98a5a`。
2. **对读屏和交互不存在：** 加 `aria-hidden="true"`、`pointer-events: none`、`user-select: none`。装饰里的字不进页面的文字内容，复制正文时也不会带上它。
3. **只在宽屏：** 留白里的批注、线描、铭文 1100px 以上才显示。手机上没有留白，硬放就会压到内容。例外是压在主体中心背后的极淡大字（`.ts-ink`）：它不占留白，手机上可以保留。
4. **不打印。** `@media print` 里隐藏。
5. **英文界面不放中文书法批注。** 西方主题可以用拉丁铭文，例如翡翠石板那句。
6. **不能让读者以为是主要信息：**
   - 颜色用褐色墨或淡金，不用正文色；
   - 放在留白里，不压在任何内容上；
   - 字号比正文小，或者大得多但极淡；
   - 不参与开场的逐层亮起。它一直在那里，像纸上原有的东西。
7. **和主题相关，内容真实，有出处。** 见下一节。

**检查：**

- 把装饰全部隐藏，页面上的信息一点不少。
- 加上装饰，第一眼看到的仍然是主体。
- 在 1100、1280、1440px 三个宽度各截一张图：装饰不压字，不和四角的竖排挤在一起。来源项目就出过《滴天髓》批注压到右上竖排的事。

## 内容：和主题相关、有出处

装饰选什么，按这个顺序想：

1. 这一页的主题，在传统里有没有一句「开宗明义」的原文？例如一门学问的经典开篇，一部书的首句。
2. 有没有和这一页的数据一起变的原文？例如日主是壬水，就写《滴天髓》论壬水的那四句。这比固定的一句更有意思。
3. 有没有和主题相关的图形？例如星斗的连线、器物的纹样。
4. 都没有，就不放。宁缺毋滥。

**出处要核对：**

- 引文要说得出书名、篇名。能找到通行本原文的，逐字对过再放。
- 拿不准原文，就问用户，或者只放图形不放字。
- **不编古文，不改写原文凑字数。** 编出来的「古语」懂行的人一眼就能看穿，整页的可信度跟着塌掉。
- 数据驱动的批注（例如每天的七十二候），用确定性的库算，不要让模型生成。来源项目用 tyme4ts 算七十二候。

## 写法

CSS 在 `code/tianshu.css` 第 ⑩ 节。

### 书法批注

在一幕的留白里竖写。第一列是小一号的「某某曰」，后面每列一句：

```html
<p class="ts-note" aria-hidden="true" style="right: calc(3% + 6px); bottom: 92px">
  <span>滴天髓曰</span>
  <span>壬水通河　能泄金气</span>
  <span>刚中之德　周流不滞</span>
</p>
```

- 位置用内联样式或单独的类，按这一页的留白调整。
- 中文界面才渲染它。英文界面在模板里直接不输出，或者加 `:root[lang='en'] .ts-note { display: none }`。

### 主体背后的大字

```html
<div class="ts-scene-main">
  <svg>…主体…</svg>
  <span class="ts-ink" aria-hidden="true">壬</span>
</div>
```

`.ts-ink` 是马善政 `min(300px, 50vw)`，不透明度 .06，`screen` 混合，居中压在主体中心。像墨渗进纸里。

### 星斗线描

北斗、南斗的星位（在一个 132×64 的小框里，按天上的样子）：

```html
<svg class="ts-motif" viewBox="0 0 132 64" aria-hidden="true">
  <!-- 北斗七星：天枢、天璇、天玑、天权、玉衡、开阳、摇光 -->
  <polyline points="4,10 8,34 40,44 50,20 76,16 100,18 126,40" />
  <circle cx="4" cy="10" r="2.6" /> <!-- …每颗星一个 circle… -->
  <text x="4" y="62">北斗</text>
</svg>
<!-- 南斗六星：4,30 30,40 56,32 80,18 104,26 96,4 -->
```

### 标题下的枯笔

一笔用 SVG 滤镜（`feTurbulence` 加 `feDisplacementMap`）做出飞白的褐色笔画，作为 data URI 背景放在标题的 `::after` 上，120×12px，不透明度 .55。见 `tianshu.css` 的 `.ts-section-title::after`。只画一次，不动。
