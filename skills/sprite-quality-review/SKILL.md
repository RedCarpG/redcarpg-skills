# 验收 Sprite 原尺寸辨识度、技术规格与动画循环

读取规格和实际 PNG。列出每项的预期值、测量值和通过/失败/未测。尺寸或透明度需要原件与代码环境；仅有截图时标为未测。

并排查看参考、1 倍图和最近邻放大图；检查发型剪影、面部辨识度、服装层次。循环至少两次观察接缝、脚底漂移和颜色闪烁。将问题定位到帧号和区域，并给出修改优先级。
